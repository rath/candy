Seven tools.
Nothing to learn.

Highlight

Draw a translucent marker over anything. Pick the color, width and opacity.

Mosaic

Drag over a name, an address or a face to pixelate it. Make the blocks as coarse as you need.

Text mosaic

Apple Vision finds every line of text, Korean and Japanese included. Check the boxes, then pixelate one or all of them.

Crop

Drag a rectangle, nudge its edges, and open that part as a new image.

Resize and rotate

Scale with the proportions locked, type exact pixel dimensions, or turn the image by 90°.

Flatten

Fill transparent areas with a solid color before saving to a format without alpha.

Eyedropper

A loupe magnifies the pixels around the pointer. Click to pin one, nudge it with the arrow keys, and copy its color as hex or RGB.

Originals stay put

The first save always creates a copy. Undo as far back as you like. Images and text recognition never leave your Mac.

Save it your way

Pick the format as you save. JPEG, HEIC, AVIF and JPEG 2000 take a quality setting; WebP can be lossless or lossy.

The same tools,
from the terminal.

Preview an image inline in a Kitty-compatible terminal, tmux included. Inspect a file’s format, size and colors without opening it. Crop, resize, rotate, mosaic and flatten with the engine the app uses, into a new file or in place. When you’d rather see what you’re doing, candy edit opens the app and hands the shell straight back. 

# Look
$ candy photo.png
$ candy inspect photo.heic
$ candy browse ~/Pictures
# Edit without leaving the shell
$ candy crop photo.png --rect 20,30,300,200 -o crop.png
$ candy resize photo.heic --width 1200 -o small.webp
$ candy rotate photo.jpg --cw --in-place
$ candy mosaic shot.png --text -o safe.png
$ candy flatten logo.png --background '#ffffff' -o flat.jpg
# Edit in the app; the shell stays free
$ candy edit photo.png

ls gives you names.
candy browse shows the pictures.

Run it in a folder of images and each one appears as you arrow down the list. Tab lays the folder out as thumbnails, Enter opens a subfolder or shows a picture large, and e sends it to the app for an edit. It runs in Ghostty and kitty, inside tmux too.

Questions

Common questions about compatibility, privacy, and how Candy handles your files.

What is Candy, and how is it different from Preview or Photoshop?

Candy is a free, MIT-licensed native macOS image editor and CLI built with Swift/AppKit and Rust, with no web view. It fills the gap between Preview and Photoshop: Preview lacks pixelation mosaic, Apple Vision text mosaic, a full-resolution eyedropper, and a terminal image browser, while Photoshop is heavy and subscription-based for quick screenshot edits.

Do my images or detected text ever leave my Mac?

No. Every edit, format conversion, and Apple Vision text-region detection runs locally on your Mac with no cloud service, account, telemetry, or network request. Because mosaic is a visual effect and text detection can occasionally miss text, always review detected boxes before sharing sensitive images.

Will Candy overwrite my original image?

Not by default. In the app, the first Save always asks for a new file and protects the original path, including symlinks and hardlinks; subsequent saves update that copy. In the CLI, editing commands write to -o and only modify the input file when you explicitly pass --in-place.

Which Macs and macOS versions are supported?

Public releases require Apple Silicon and macOS 14 (Sonoma) or later, and are signed with a Developer ID and notarized by Apple. The interface follows macOS in English, Korean, and Japanese. Windows, Linux, and iOS are not supported; Intel Macs can build from source with Rust and Xcode.

Which terminals work with inline image previews and candy browse?

Automatic inline display and candy browse work in Ghostty and kitty, both directly and inside tmux with allow-passthrough enabled. In unsupported terminals, candy <file> automatically falls back to opening the native Mac app. Piped input like cat photo.png | candy is also supported.

What are Candy’s format support and current limits?

Candy opens everything macOS Image I/O decodes (including PNG, JPEG, WebP, HEIC, AVIF, GIF, TIFF, BMP, PSD, and full-resolution camera RAW) plus SVG and SVGZ, and exports ten raster formats with quality controls. Images are edited as 8-bit sRGB up to about 64 megapixels (512 MiB input); Candy does not have layers, animation editing, or SVG export.

Changelog

What each release added or fixed. The full notes are on GitHub.

  1. 0.4.0 Nov 23, 2026

    New candy browse pages through a folder of images in the terminal, with a preview beside the list or a grid of thumbnails, and walks into subfolders as it goes. Press e to edit the selected image in the app. Camera RAW files now open at full resolution.

  2. 0.3.5 Nov 15, 2026

    An eyedropper magnifies the pixels under the pointer. Pin one, nudge it with the arrow keys, and copy its color as hex or RGB, read from the full-resolution image.

  3. 0.3.4 Nov 15, 2026

    Text mosaic applies to the selected box or to all of them, leaving the rest to review. Cancel or Escape clears the boxes without touching the image or its undo history.

Earlier versions
  1. 0.3.3 Nov 12, 2026

    Repeated edits and undo are faster, since Candy no longer replays the whole history. Saving a copy works after the original moves, transparent previews keep clean edges, and SVG text uses system fonts.

  2. 0.3.2 Nov 3, 2026

    Piped images display directly: cat image.png | candy. Previews no longer come up blank in local tmux sessions while another pane plays video or sends graphics.

  3. 0.3.1 Oct 21, 2026

    A smaller download: the app executable is now stripped of its symbols, as the bundled CLI already was. Nothing else changed.

  4. 0.3.0 Oct 21, 2026

    SVG and SVGZ files open everywhere a bitmap does: the editor, Finder’s Open With, drag and drop, terminal previews, candy inspect and every editing command.

  5. 0.2.4 Oct 14, 2026

    Set the quality of JPEG, WebP, HEIC, AVIF and JPEG 2000 exports with a slider or --quality, and save WebP with lossy compression. Each document remembers its save settings.

  6. 0.2.3 Oct 14, 2026

    Fixes the malware warning macOS showed the first time a downloaded copy opened. The app no longer carries build-machine paths that Gatekeeper could not verify.

  7. 0.2.2 Oct 13, 2026

    A Japanese interface that follows your macOS language and uses macOS’s own Japanese terms for standard commands. The website gained a Japanese page.

  8. 0.2.1 Oct 11, 2026

    A Korean interface. Candy opens almost any image macOS can read, saves to seven more formats including HEIC and AVIF, rotates by 90°, and edits files in place with --in-place.

  9. 0.2.0 Oct 11, 2026

    Inline previews work inside tmux, the new candy inspect reports a file’s format, size and colors, and editor windows open sized to the image.

  10. 0.1.1 Oct 11, 2026

    A new lollipop app icon for Finder and the Dock, with a matching mark and favicon on the website.

  11. 0.1.0 Oct 11, 2026

    The first release: a native Mac app with highlight, mosaic, text mosaic, crop, resize and flatten, and the candy command for the same edits in the terminal.
