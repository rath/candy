이미지 편집,
간단하게.

강조할 때는 형광펜으로, 가릴 때는 모자이크로. Candy는 간단한 이미지 편집을 빠르게 끝낼 수 있는 Mac 앱입니다. 필요한 부분만 수정해 새 파일로 저장하세요.

macOS 14 이상 · Apple Silicon · 무료 · 오픈소스

터미널에서 바로 보고,
앱에서 편집하세요.

Kitty 그래픽을 지원하는 터미널에서는 tmux 안에서도 이미지를 바로 볼 수 있습니다. candy inspect 명령은 파일을 열지 않고 포맷과 크기, 색상 정보를 보여 줍니다. 자르기, 크기 조절, 모자이크, 배경 채우기는 앱과 같은 엔진으로 터미널에서 바로 처리할 수 있습니다. 화면을 보며 편집하려면 candy edit 명령으로 이미지 크기에 맞춘 앱 창을 띄우세요. 탭과 단축키, 저장 창까지 익숙한 Mac 방식으로 사용할 수 있습니다. 

# 바로 보기
$ candy photo.png
$ candy inspect photo.heic
# 터미널에서 편집
$ candy crop photo.png --rect 20,30,300,200 -o crop.png
$ candy resize photo.heic --width 1200 -o small.webp
$ candy mosaic shot.png --text -o safe.png
$ candy mosaic shot.png --rect 40,80,300,60 -o safe.png
$ candy flatten logo.png --background '#ffffff' -o flat.jpg
# 앱에서 편집, 터미널은 그대로
$ candy edit photo.png

필요한 부분만 잘라내기

원하는 부분을 선택해 별도 이미지로 만드세요. 선택한 영역의 위치와 크기도 자유롭게 조절할 수 있습니다.

형광펜으로 강조하기

눈에 띄어야 할 부분에 형광펜을 그어 보세요. 색상과 굵기, 불투명도를 원하는 대로 조절할 수 있습니다.

민감한 정보 가리기

가리고 싶은 부분을 선택해 모자이크를 적용하세요. 이미지 속 한글과 영문을 자동으로 찾은 뒤, 인식된 영역을 확인하고 가릴 수도 있습니다.

크기 조절하기

가로세로 비율을 유지하며 크기를 바꾸거나, 원하는 너비와 높이를 직접 지정하세요.

투명한 배경에 색 채우기

이미지의 투명한 부분을 원하는 색으로 채우세요. 투명도를 지원하지 않는 형식으로 저장할 때도 유용합니다.

원본은 그대로 보관

처음 저장할 때는 새 파일을 만들어 원본을 보존합니다. 편집 중에는 실행 취소와 다시 실행도 가능합니다. 이미지 편집과 문자 인식은 모두 Mac에서 처리합니다.

열기   PNG · JPEG · WebP · HEIC · AVIF · GIF · TIFF · BMP · PSD · RAW 등 Mac이 읽는 모든 형식

저장   PNG · JPEG · HEIC · WebP · AVIF (macOS 26) · TIFF · GIF · BMP · JPEG 2000 · TGA

무료로 사용하세요.
소스 코드도 공개합니다.

Candy는 MIT 라이선스로 공개된 오픈소스 앱입니다. Homebrew로 앱과 터미널 명령어를 함께 설치하거나, 아래 링크에서 앱을 다운로드하세요.

Mac용 Candy 다운로드 
brew install --cask rath/tap/candy

macOS 14 이상이 설치된 Apple Silicon Mac에서 사용할 수 있습니다. Developer ID로 서명하고 Apple 공증을 받은 앱으로, 별도의 빌드 과정 없이 설치해 사용할 수 있습니다.

Candy — 간단한 이미지 편집을 더 편하게.
