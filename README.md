# Candy

A small image tool for your Mac: view images in a Kitty-compatible terminal,
then open an editor when you need to make changes.

Rust workspace: `candy-core` for image operations, `candy-macos` for Image I/O
and Vision, and `candy` for the CLI and egui editor. Requires macOS 14+ and
Rust 1.95+. This repository is under initial development.
