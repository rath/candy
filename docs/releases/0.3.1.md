Candy 0.3.1 strips the app executable, shrinking the download.

## What's changed

- The app executable is now stripped of its symbol table, as the bundled CLI
  already was. The app bundle is 6.5 MB instead of 8.4 MB, and the download is
  smaller to match.
- No functional changes since 0.3.0, which added SVG support.

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.3.1-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
