Candy 0.2.2 speaks Japanese.

## What's changed

- The editor follows your macOS language: English, Korean, or now Japanese when macOS prefers it. Menus, tools, contextual controls, status messages and the save and close dialogs are translated, using macOS's own Japanese terms for standard commands (取り消す, 別名で保存…, ウインドウに合わせる) and 蛍光ペン, モザイク and 背景の塗りつぶし for the tools. Detailed error messages from the image engine remain in English.
- The website has a Japanese page at [candy.told.me/ja/](https://candy.told.me/ja/), with the editor recorded in the Japanese interface.

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.2.2-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
