Candy 0.3.3 makes repeated edits faster and improves save safety, transparent
previews and SVG text rendering.

## What's changed

- Apply new edits directly to the current image instead of replaying the entire
  edit history. Undo and redo reuse rendered checkpoints, bounded to 64 MiB and
  16 checkpoints per document.
- Keep saving a copy after the original file is moved or deleted. Original-file
  protection still follows moved files, symlinks and hardlinks, including when
  saving an extracted selection.
- Preserve transparent edges when reducing previews in the editor and terminal,
  avoiding color fringes from invisible pixels.
- Load system fonts when resolving SVG text, including namespaced text and text
  inside nested SVG images.
- Reject oversized input before decoding: encoded files and stdin are limited
  to 512 MiB; SVG/SVGZ input and cumulative decoded XML, including nested SVGs,
  are limited to 32 MiB.
- Ensure app and test builds relink against the updated Rust image engine when
  its static library changes.

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.3.3-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
