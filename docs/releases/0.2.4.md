Candy 0.2.4 adds export quality controls and lossy WebP compression to the app and CLI.

## What's changed

- Adjust JPEG, WebP, HEIC, AVIF and JPEG 2000 quality from 1–100. The native save
  sheet has a slider and numeric input, with Korean and Japanese translations.
- Choose lossless or lossy WebP compression. The lossy encoder is bundled with
  Candy, preserves transparency and needs no extra installation.
- Each document remembers its successful save settings by format for Save and
  Save As. Cancelling or failing a save leaves the previous settings intact.
- CLI editing commands accept `--quality` and `--webp-mode lossless|lossy`.
  WebP quality requires `--webp-mode lossy`; incompatible options are rejected
  before changing the output file.
- Existing defaults remain: JPEG quality 92, HEIC/AVIF/JPEG 2000 quality 85,
  and lossless WebP. Switching WebP to lossy starts at quality 80. AVIF quality
  100 avoids Image I/O's failing maximum-quality endpoint.

```sh
candy resize photo.png --width 1200 -o photo.jpg --quality 80
candy resize photo.png --width 1200 -o photo.webp --webp-mode lossy --quality 80
candy rotate photo.heic --cw -o rotated.heic --quality 90
```

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.2.4-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
