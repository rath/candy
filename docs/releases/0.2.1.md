Candy 0.2.1 speaks Korean, opens almost any image your Mac can read, saves to seven more formats, and rotates.

## What's changed

- The editor follows your macOS language: English, or Korean when macOS prefers it. Menus, tools, contextual controls, status messages and the save and close dialogs are translated, using macOS's own Korean terms for standard commands. Detailed error messages from the image engine remain in English.
- Candy opens anything Image I/O decodes, no longer just PNG, JPEG, WebP, HEIC and AVIF: GIF, TIFF, BMP, JPEG 2000, PSD, TGA, ICO, ICNS, OpenEXR, Radiance HDR, PBM, camera RAW and DNG, and JPEG XL on macOS 26 or later.
- Saving adds HEIC, TIFF, GIF, BMP, JPEG 2000 and TGA, plus AVIF where macOS can encode it, to PNG, JPEG and lossless WebP. The save panel's Format popup lists only formats this Mac can write, and the CLI picks the format from the output extension.
- Rotate a quarter turn in either direction with the new Rotate left and Rotate right buttons in the Resize strip, or with `candy rotate --cw` and `--ccw`.
- `-i`/`--in-place` replaces the input file: the result is re-encoded in the file's own format and swapped in atomically, keeping its permissions and following a symlink to the file it points at. Without it, edits still need `-o`, and `--force` never overwrites the input.
- Replacing an existing output now keeps that file's permissions instead of leaving it readable only by you.
- The empty window is down to one instruction and an Open image… button.

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.2.1-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
