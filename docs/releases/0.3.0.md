Candy 0.3.0 opens SVG files in the app, the terminal and the CLI.

## What's changed

- SVG and SVGZ files open everywhere a raster image does: the editor window,
  Finder's Open With, drag and drop, inline terminal previews, `candy inspect`
  and the editing commands. Crop, mosaic, text detection, resize and export
  work on the rendered pixels.
- A vector document has no pixel size of its own, so Candy renders it at its
  intrinsic size, enlarged so the longer side is at least 1024 pixels and
  reduced to fit the 64-megapixel limit. Transparency is preserved, and
  `candy inspect` reports the rendered size.
- Text inside an SVG is set with the fonts installed on your Mac, with
  fallbacks for scripts such as Korean. Nested SVG `<image>` references render;
  bitmaps embedded in an SVG are skipped to keep the app small.
- Edited SVGs save in any raster format. Candy does not write SVG.
- Release builds now use fat link-time optimization and size-optimize the
  bundled SVG renderer, so the CLI grows by under 1 MB for the new format.

```sh
candy diagram.svg
candy inspect icon.svg
candy resize icon.svg --width 512 -o icon.png
```

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.3.0-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
