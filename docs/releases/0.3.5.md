Candy 0.3.5 adds an eyedropper for reading exact pixel colors.

## What's changed

- Choose **Eyedropper** (Cmd+7) to read the color under the pointer. A loupe
  beside the pointer magnifies the surrounding 11 × 11 pixels and shows the
  center pixel as hex (`#faac30`) and decimal (`250, 172, 48`).
- Click to pin a pixel, then move the pin one pixel at a time with the arrow
  keys, or ten with Shift. Escape clears the pin.
- Click the Hex or RGB value above the canvas to copy it, or press Cmd+C to
  copy the hex value.
- Colors are the 8-bit sRGB pixels Candy edits and exports, read at full
  resolution even when the window shows a reduced preview. A pixel that is not
  opaque adds its alpha (`#faac3080`, `250, 172, 48, 128`).
- Korean and Japanese interface text uses macOS's own terms (스포이드, スポイト).

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.3.5-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
