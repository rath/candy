Candy 0.1.1 adds a new lollipop app icon and refreshes the website's visual identity.

## What's changed

- Added a native app icon for Finder, the Dock, and the About panel, with simplified artwork for small sizes.
- Updated the website with a matching lollipop favicon and brand mark, an outlined Fredoka wordmark, and a coastal image-editing demo.
- Added localized social preview images and search metadata, and improved the Korean website copy.
- Updated synthetic image fixtures and enabled automatic website publishing from the main branch.

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.1.1-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
