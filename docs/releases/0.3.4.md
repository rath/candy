Candy 0.3.4 makes text mosaic easier to review, apply and cancel.

## What's changed

- Separate **Apply to selected** from **Apply to all**. Applying to one text box
  leaves the remaining boxes available for review and further editing.
- Show **Cancel** after text detection. Cancel or press Escape to clear the
  remaining boxes without changing the image or its undo history. Escape during
  a drag still cancels only that drag.
- Keep the detection and application buttons visible first in compact windows,
  and update Korean and Japanese interface text.
- Update the indirect `rustix` dependency to 1.1.6, addressing
  [RUSTSEC-2026-0486](https://rustsec.org/advisories/RUSTSEC-2026-0486.html).

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.3.4-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
