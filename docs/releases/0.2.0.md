Candy 0.2.0 brings inline previews to tmux, adds `candy inspect`, and opens editor windows sized to the image.

## What's changed

- Inline previews now work inside tmux: images travel through tmux passthrough with Kitty Unicode placeholders, and automatic detection asks tmux whether passthrough is enabled and the client is Ghostty or kitty.
- Added `candy inspect`, which reports a file's format, dimensions, EXIF orientation, color model, bit depth, alpha, color profile and DPI from its headers, followed by statistics of the decoded pixels. `--json` prints the same report for scripts.
- Editor windows opened for a file appear once the image has loaded, already sized so it shows at Actual Size, or as large as the screen allows. Tabbed, full-screen and manually resized windows keep their size.
- The tool selector uses icons with tooltips, and the window minimum shrank to 560 × 320 points, so small images no longer sit in a mostly empty window.
- The bundle identifier is now `me.told.candy.app`.

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.2.0-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
