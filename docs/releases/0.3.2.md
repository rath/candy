Candy 0.3.2 adds piped image input and fixes blank previews in local tmux sessions.

## What's changed

- View images from stdin: `cat image.png | candy`, `candy < image.png`, or
  `cat image.png | candy -`. Use `--display gui` to open piped images in the editor.
- Fix blank previews in local Ghostty/tmux sessions when another pane is playing
  video or sending graphics. Candy now hands off a private temporary PNG in one
  command, avoiding interrupted image uploads.
- Clean up temporary previews on failure and report a timeout if the terminal
  does not consume the file. SSH sessions keep inline transfer.
- Document tmux's `allow-passthrough all` setting and stdin usage.

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.3.2-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
