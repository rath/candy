Candy 0.4.0 adds `candy browse`, an image browser that runs in the terminal.

## What's changed

- Run `candy browse` in a folder, or pass a folder to `candy`, to page through
  its images with a preview beside the list. `candy browse photo.heic` opens
  the folder with that file selected.
- Folders are listed too: Enter opens one, Backspace returns to the parent,
  and a selected folder previews its first image and counts what it holds.
- Tab switches to a grid of thumbnails, with arrow keys moving across and
  between rows. Enter shows the selected image large; Enter or Esc goes back.
- Press `e` to open the selected image in Candy and keep browsing, `r` to
  rescan the folder, and `q` to quit.
- The browser runs in Ghostty and kitty, directly or inside tmux with
  `allow-passthrough` enabled. Previews are decoded at the size they are shown,
  so large photos and folders stay quick.
- Camera RAW files now open at full resolution. Candy previously could show
  the small TIFF thumbnail embedded in some RAW files instead.

## Install or update

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

For an existing installation, quit Candy and run:

```sh
brew update && brew upgrade --cask candy
```

Or download `Candy-0.4.0-macos-arm64.zip`, unzip it, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple.
