Candy's first release: a small native image tool for macOS, with a Swift/AppKit
editor and a Rust command-line interface.

## Install

Requires **Apple Silicon and macOS 14 (Sonoma) or later**.

```sh
brew install --cask rath/tap/candy
```

Or download `Candy-0.1.0-macos-arm64.zip`, unzip, and drag `Candy.app` to
Applications. The app and bundled CLI are signed with Developer ID and notarized
by Apple. No Rust or Xcode installation is needed.

## Features

- View images in a Kitty-compatible terminal or open the native editor.
- Extract a region, apply mosaic, highlight, resize, or flatten transparency.
- Detect text regions locally with Apple Vision, review the boxes, then mosaic.
  Korean and English text are supported; detection avoids OCR language-model
  startup, including on images with no text.
- Open PNG, JPEG, WebP, HEIC and AVIF; save PNG, JPEG and lossless WebP.
- Use native menus, document windows and tabs, undo/redo, and save-copy protection.
- Edit from the CLI with `resize`, `crop`, `mosaic`, and `flatten`.

## Current limits

Intel binaries are not included. Text detection may miss text or select graphics;
review every result before sharing. Images are processed as 8-bit sRGB, only the
first frame is loaded, and exports do not retain source metadata or HDR data.
Automatic terminal display falls back to the editor inside tmux/screen.
