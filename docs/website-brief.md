# Candy landing page

Scope: static GitHub Pages site at candy.told.me. English `/`, Korean `/ko/` and Japanese `/ja/`; explicit language links, complete content without JavaScript. Persuade mode. Reuse the product's coral accent and honest native macOS presentation. Do not replace the native application's design system.

## Direction contract

THESIS: A compact product introduction that shows the real editor and returns visitors to their work. Simple landing page, not a separate product or elaborate campaign.

OWN-WORLD: White, deep ink, coral image stage, familiar rounded controls, clear sans-serif lettering. Actual native screenshot is the main visual; no invented app UI or testimonials.

STORY: Understand the small-edit workflow, see the six capabilities, discover terminal integration, then install with Homebrew or download the signed app. macOS 14+, local OCR and original protection are factual proof.

FIRST VIEWPORT: Name and language links; generous headline and concise copy beside a coral stage playing a recording of the real editor in the page language. Install action is beside GitHub. A command strip begins the second section.

FORM: Direct code-led implementation of the user's narrow request for a simple introduction, extending Candy's established coral/native identity. No new visual-world selection or generated comp.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Asset provenance: site/assets/candy-demo-en.mp4, candy-demo-ko.mp4 and candy-demo-ja.mp4 are real recordings of the Candy AppKit window editing made-up scenes (scripts/demo/scenes/) in the light appearance, with the interface in the page language. Every mosaic and highlight was applied by Candy; no application UI is fabricated or composited. candy-editor-en.png, candy-editor-ko.png and candy-editor-ja.png are window captures of the finished order page, used as posters, reduced-motion images and social-card sources. No personal data. See site/assets/credits.txt.

Social sharing: language-specific 1200 × 630 cards use the language's real editor still, coral stage, warm paper and large localized headlines. The authored export source is scripts/og/index.html; the static PNGs live in site/assets/og-en.png, og-ko.png and og-ja.png. Each page points search and social crawlers to its own language, while canonical and reciprocal hreflang links connect all three versions.
